# 🥽 AR/VR Lab 6 – Interactive Three-Section Web Experience

An interactive **AR/VR Lab 6 web application** designed to demonstrate multiple visual sections through a simple and engaging button-based interface. The application contains **three interactive sections**, where users can click the corresponding buttons to dynamically switch between different content and visual experiences.

## ✨ Features

* 🎯 **Three Interactive Sections** – Navigate between three different AR/VR-related sections.
* 🖱️ **Button-Based Navigation** – Each button dynamically changes the displayed section.
* 🖼️ **Visual Content** – Uses dedicated images to enhance the interactive experience.
* ⚡ **Dynamic UI Interaction** – Content updates instantly without reloading the page.
* 📱 **Responsive Web Interface** – Designed for a clean and accessible user experience.
* 🎓 **Academic AR/VR Lab Project** – Developed as part of the AR/VR laboratory coursework.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Interactive UI Design
* AR/VR Concepts

## 🚀 How It Works

1. Open the web application.
2. The interface displays the available three sections.
3. Click any section button.
4. The corresponding content and visual representation are displayed.
5. Users can switch between the three sections interactively.

## 🎯 Objective

The objective of this lab is to demonstrate **interactive web-based AR/VR concepts** by creating a simple interface that allows users to explore multiple visual sections through button-based navigation and dynamic content switching.
